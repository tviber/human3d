# 肌肉驱动投掷与直拳

这里记录的是 MyoSim 肌肉—肌腱参数、MuJoCo 正向积分，以及动作捕捉 / 研究分期所约束的动作实验。它不是人体数字孪生、医疗模型或经运动员标定的预测系统。

## 力学模型与边界

固定版本为 `myo-sim==0.2.3`、MuJoCo `3.6.0`。完整源模型保留 123 个关节、416 个肌肉执行器、424 条肌腱路径、51 个关节耦合 / 等式约束，以及 104 个刚体的质量和惯性参数。MyoSim 的 Apache-2.0 许可副本在 `assets/source/dynamics/MYO-SIM-LICENSE.txt`。

- `assets/source/dynamics/myofullbody-complete.xml` 和 `myofullbody-parameters.json` 保存完整源模型及逐项参数清单。
- `public/dynamics/musculoskeletal.xml` 和 `model.json` 是网页重放所用的降阶模型。它有 `nq=52`、`nv=50`，即 44 个关节自由度和 6 个浮动根速度自由度；两侧肩 / 肘、躯干、双侧髋膝踝以及右侧前臂、腕、拇指和四指可动。双足由固定支撑夹具固定；左腕手、肩胛和部分腰椎细分固定。
- 动作优化使用完整 416 路执行器的有界激励。网页读取已经积分的 100 Hz 状态，不在浏览器实时求解肌肉控制。

肌肉激励经上游激活动力学、力长 / 力速关系和肌腱路径产生关节力矩；支持和关节约束提供约束反力。简化表示为：

```text
M(q) q̈ + C(q,q̇) + g(q) = R(q) F_m + J(q)ᵀ λ
```

`R(q)` 来自肌肉作用线与关节力臂，`Jᵀλ` 包含支撑和约束反力。求解器以动作任务曲线为跟踪目标，计算有界肌肉激励；积分时不外加关节电机扭矩或逐帧写入目标姿态。屏幕的肌肉显示是模型中的张力 / 激活变量，不是 EMG、真实肌肉尺寸或人体皮肤的肌肉收缩变形。

“动力链”不是一股力依次从地面传到手。关节力矩、角动量、功率、躯干与肩胛耦合共同形成节段间的能量交换；任务曲线描述动作意图，最终显示的是受肌肉能力、惯性和固定支撑影响后的仿真响应。

## 无球原地棒球式上手投掷

投掷分期参考 [CMU Subject 124 的 124_01 Baseball Pitch](https://mocap.cs.cmu.edu/search.php?subjectnumber=124) 和公开的棒球投球生物力学研究；项目文件为 `assets/source/124_01.bvh`。该捕捉包含跨步和支撑切换，直接映射到本项目固定足模型会产生不合适的脚与躯干姿势，因此当前动作改用 `assets/motions/baseball-throw.json` 的 `dynamics.action` 中的骨盆相对任务关键帧。CMU 文件只用于核对动作分期，当前可视姿态不是原始捕捉的逐帧重放，坐标 / 角度均标为工程近似。

研究将投球分为准备、跨步 / 早期蓄力、晚期蓄力、加速、减速和随挥；常见的上手投球在肩外旋蓄力后进入肩内旋与肘伸展加速，躯干向前 / 侧向运动参与能量交换。[临床动作分期与姿态综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC9950989/) 也强调前足落地、前腿伸展、骨盆和躯干转动的协调；一项投球动力学生物力学综述报告骨盆峰值旋转速度通常早于上躯干峰值约整个投球周期的 18–22%。[棒球投球生物力学综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC3445126/)

本实验把这条顺序收敛为“下肢加载 → 骨盆启动 → 躯干滞后跟进 → 肩 / 肘加速 → 手腕和手指放松 → 随挥减速”。具体关键帧和时间不是受试者均值，也没有据此反推真实肌肉激活；它们是按文献时序组织的工程任务，由 416 路肌肉模型正向响应。无球、无可见物体、无释放事件、无飞行或碰撞。脚保持原地，不包含真实投球的跨步、着地和前腿制动；所以界面称“原地投掷研究”，不声称完整投手仿真。

最新基线记录中，骨盆偏航角速度峰值约 −125°/s（0.37 s），胸廓轴向角速度峰值约 +126°/s（1.50 s）；峰值时序在该原地记录中相差约 1.13 s，能量传递不是一条简单的逐关节力传送带。最大骨盆转角约 −29.4°（1.09 s），最大胸廓轴向角约 −17.2°（1.33 s）。这些是当前合成记录的数值，不是研究中的人体群体均值。支撑漂移约 0.05 mm，最小前臂—躯干净间距约 0.168 m，最大标量软限位超出约 1.12°；任务手端最大误差约 0.220 m、平均约 0.039 m。显示蒙皮把物理肩—肘链的方向和肘角重定向到 MakeHuman 肩点，并保持可视肢段长度；所以肩肘姿态和骨长一致，但蒙皮手端与物理手端仍可能相差数厘米至约 22 cm。

记录中的腕关节从最大蓄力时约 −33.5°（MyoSim 坐标为后伸）转向出手时约 +45.2°（屈曲），接近降阶模型的 +45°软限位。这里用户提出的 250°→80°被解释为手掌在画面中的平面朝向变化，绝不是腕关节可以活动 170° 的解剖 ROM。投球研究支持蓄力后伸、加速期向屈曲变化，但具体幅度随投球类型 / 速度而异；本动作把腕角关键帧限制在模型可用范围内。[投球腕部运动学](https://pubmed.ncbi.nlm.nih.gov/7661258/)；[加速阶段腕屈曲研究](https://pubmed.ncbi.nlm.nih.gov/23764035/)。

12 个物理手指屈曲坐标的和在最大蓄力约 405°、释放约 333°，手指伸肌没有把肌肉状态带到完全伸开。可见皮肤手在蓄力阶段保持包拢，释放帧通过 `task-keyframe-retarget` 达到约 22°的关节旋转量（该和数仅是骨骼旋转幅值的画面诊断，不是解剖指标）；仿真记录中的手指 q 值仍原样保留。球投出前后手指运动有运动学依据，[棒球释放前手指运动研究](https://pubmed.ncbi.nlm.nih.gov/28632054/)，但本项目把可见放手姿势作为明确的渲染近似，不把它冒充为 MyoSim 的肌肉驱动结果。无球、无可见物体、无释放事件、无飞行或碰撞。脚保持原地，不包含真实投球的跨步、着地和前腿制动。

## 直拳与握拳

直拳不再使用 CMU 的通用 `punch/strike` 片段。动作方向参考 8 名精英业余拳手的后手直拳运动学研究（拳端主要向前、略向上并轻微内收）及 cross / hook / uppercut 的三维运动分析；圆弧更明显的轨迹属于勾拳 / 上勾拳，不应套在直拳上。[直拳运动学研究](https://doi.org/10.18869/acadpub.aassjournal.2.2.39)；[三类拳击动作的三维分析](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2020.598861/full)。研究支持相对方向与节段顺序，不提供本模型中全部个体关节角，因此精确目标仍明确标为工程近似。

`assets/motions/punch.json` 的 `dynamics.action` 使用有界肩球旋转向量与肘屈伸铰链关键帧，时间曲线通过 quaternion `RotationSpline` 与 Hermite 插值平滑生成。右拳从同侧肩后、低位的收拳位起动，骨盆 / 躯干先转，肩肘随后加速；手端主要向前并略向上，收窄在同一肩线附近，起始与伸展帧的横向位移控制在 8 cm 内。实际基线仿真起拳时，拳端位于肩后约 13 cm、低于肩约 20 cm；回收段受肌肉跟踪能力限制，回到躯干前侧的紧凑重置位，而非精确复现同一个后下收拳位。目标姿态按固定骨段长度和躯干净距检查，肌肉仿真仍只跟踪关节状态，不在网页逐帧写入关节姿态。左拳停留在模型的脸侧护架，显示网格对左手手指使用独立的握拳关节角；此手指姿态是可视蒙皮近似，不包含左手肌肉驱动。

拳指姿势用 `assets/motions/punch.json` 的 `dynamics.action` 逐节 MCP、PIP、DIP 与拇指 CMC、MCP、IP 目标驱动可见手；MyoSim 物理记录仍含这些 DOF，但弱肌力案例会让拇指 IP 偏离闭拳目标。伸展关键帧还要求腕屈伸保持 −6°、短暂停留 −2°；相关拳击测量通常把击中附近的手腕维持在相对中立位置，而不是要求极端屈伸。[拳击冲击附近的手腕运动研究](https://pubmed.ncbi.nlm.nih.gov/34872457/)。基线物理记录在 1.7 s 实际腕屈曲却约 +36.4°，短暂停留时约 −2.8°；因此可见皮肤手只对腕末端按任务角度重建。此时用皮肤手掌相对前臂的夹角测得分别约 0.75° / 3.25°，同时记录保留物理腕角，不能把画面校正说成肌肉仿真已实现中立腕。

在 1.7–1.975 s 伸展 / 停留阶段，蒙皮肘内角、肩至腕方向和手指接触曾由浏览器画面复验；对应预设已从动作库移除，旧浏览器入口不再维护。`dynamics:test` 只检查物理记录与数值约束，不代表蒙皮没有穿插。这些是当前模型的几何边界，不包括皮肤厚度、撞击、接触力或人体伤害风险。右拳在回收到护架时保持握拳，左拳在动作全程保持闭合护手，不再把放松张开的手冒充直拳姿态。

## 数值、画面与证据

使用 `npm run dynamics:validate` 校验 JSON、源数据和模型参数，`npm run dynamics:build -- baseball-throw` 或 `-- punch` 重新优化激励、正向积分并导出记录，`npm run dynamics:test -- baseball-throw punch` 检查记录布局、肌肉激活、虚功恒等式、约束漂移、关节限制和末端跟踪误差。投掷与直拳不再作为主界面的预设动作；其底层记录与数值验证仍保留。旧的 `qa:dynamics` 浏览器入口已随预设入口移除。

截图、录屏和本次实测误差写入 `docs/QA.md` 与 `evidence/dynamics-results.json`。测试通过只说明该版本记录满足明示的数值包络，不构成人体生物力学验证。肌肉路径不驱动可见表面组织膨缩；表面网格根据刚体段姿态做分段重定向，二者不是同一套连续有限元组织模型。
