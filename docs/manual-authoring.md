# 手工动作编辑

编辑器只支持用户手工摆姿势并记录关键帧。它不根据末端位置推算中间关节，不自动修正脚步、支撑、碰撞或姿势质量。

## 动作文件

动作采用 JSON 格式 `h3d-manual-motion` 版本 1。每个关键帧保存：

- `time`：关键帧秒数。
- `pose.root`：角色整体 X/Y/Z 位移，单位为米。
- `pose.bones`：模型骨骼名到相对 GLB 原始局部旋转的四元数偏移 `[x, y, z, w]` 的映射。

关键帧之间对每个已记录关节分别执行最短弧四元数插值。未记录的关节保持 GLB 的原始局部旋转。动作最多 120 帧，时长为 0.1 到 60 秒。

循环动作的末帧必须早于循环时长，播放器会在末帧和首帧之间继续插值。

动作格式的导入入口是 `parseMotion`。它拒绝无效的版本、时长、关键帧、向量和零四元数；导入后会规范化四元数并按时间排序。

## 存储与边界

动作库保存在浏览器 `localStorage`，建议同时导出 JSON 作为备份。更换浏览器或清理站点数据会清除本机动作库。

编辑器直接驱动 `chibi-sports-avatar.glb` 中的蒙皮骨骼。项目不再包含旧全身模型、求解器、动力学模拟、HTTP 动作服务、演示动作、解剖资料或相应的大型研究数据。
